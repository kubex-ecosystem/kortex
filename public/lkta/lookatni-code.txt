# 🧠 Kortex: AI-Driven Cloud Orchestration Interface

O Kortex é a camada de interface inteligente do ecossistema Kubex. Ele se comunica com MCPs locais/remotos, provê dashboards, interações com clusters Kubernetes e integrações com ferramentas DevOps modernas. 100% modular e com suporte a extensões.

## Principais recursos
- Painel de controle unificado
- Integração com múltiplos MCPs
- Conectores com Horizon, Kosmos, Synex
- Suporte a webhooks e controle assíncrono

## Objetivo
Tornar a gestão de infra, devops e AI orquestration simples e acessível para qualquer perfil técnico.

/// background.js ///
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.action === "ping_mcp") {
    fetch("http://localhost:3002/health")
      .then((res) => res.json())
      .then((data) => sendResponse({ ok: true, data }))
      .catch((err) => sendResponse({ ok: false, error: err.toString() }));
    return true; // async response
  }
});

/// popup.js ///
document.getElementById("ping").addEventListener("click", () => {
  chrome.runtime.sendMessage({ action: "ping_mcp" }, (response) => {
    const pre = document.getElementById("result");
    pre.textContent = response.ok
      ? JSON.stringify(response.data, null, 2)
      : `Error: ${response.error}`;
  });
});
