## Kortex – Real-Time Monitoring for DevOps & AI

> Production-ready dashboard for monitoring GitHub, Azure DevOps, and AI pipelines in real-time. Built for modern developer workflows.

---

## ⚡ Key Capabilities

- Live API rate limit tracking (GitHub, Azure)
- WebSocket powered updates (no reloads)
- Secure token-based authentication
- Auto-pause before hitting API quotas
- Visual status cards and charts
- Full configuration from UI (no .env editing)

---

## 🔌 Integrates With

- ✅ GitHub REST API (Repositories, PRs, Usage)
- ✅ Azure DevOps Pipelines
- ✅ LLM Agents from TimeCraft AI
- ✅ MCP Server (StatusRafa)

---

## 🧠 Designed For

- Backend engineers needing API observability
- DevOps teams tracking GitHub + CI/CD providers
- AI teams managing LLM execution and cost
- Developers building offline-first, real-time apps

---

## 🚀 Demo Locally

```bash
git clone https://github.com/rafa-mori/kortex.git && cd kortex
npm install && npm run dev
```

Requires backend MCP Server running at port `3002`.
